# Proyeto final de Algebra Lineal 

Para ejecutar el proyecto, desde el archivo principal utilice `` java -jar  .\target\AL1-1.0-jar-with-dependencies.jar``. Tambien se puede ejecutar con Maven utilizando ``mvn exec:java``, aunque se necesita instalar maven para esto.

Los archivos principales se encuentran en ``src/main/java/encription/Matrix`` siendo el resto auxiliares para la conexión a otras máquinas y la impresión/lectura de pantalla. Notese que en Linux la función de backspace no funciona debido a la forma que se interactua con la terminal; este problema no ocurre en Windows.
